# 大喝特喝 · iOS / Web / Mac

Discover your Cocktail DNA：通过本地八维风味档案、口味小测、评价和可解释推荐，发现自己喜欢什么，以及下一杯可以尝试什么。共用吧台、材料匹配、动画跟做与月历日记串联完整流程，无账号或外部 AI 依赖。Windows 测试可双击 `启动网页版.cmd`，或运行 `npm.cmd start` 后打开 `http://127.0.0.1:5173`。跨平台运行、功能边界和数据迁移见 [README-CROSS-PLATFORM.md](README-CROSS-PLATFORM.md)。以下保留原 iOS 功能说明。

这是从 `60款鸡尾酒配方整理.docx` 和 `60款世界著名鸡尾酒调法.docx` 校对整理出来的 SwiftUI 离线应用，适合在 iPhone 上查看配方。

## 内容

- 145 款内置鸡尾酒配方（原有 120 款，加上 25 款有 IBA 来源的精选配方）
- 中文名、英文名、配料、杯型、做法
- 模糊搜索酒名、基酒和配料，并按相关度显示结果
- 基酒筛选
- 收藏功能
- 添加自己的配方，本地保存
- 添加配方页支持“小红书导入”：打开小红书搜索、粘贴小红书整段分享文案或帖子链接尝试自动读取正文和封面图；普通读取失败时会改用内置网页读取器继续识别；识别时会忽略 `#` 后面的标签内容，并避开“小红书”这类平台标题；也可粘贴帖子正文自动识别配方，一键加入我的配方库，并保存帖子图片为本地缩略图
- “我的”筛选，只看自建配方
- “我的酒”库存，可维护自己已有的配方酒类
- 搜索框固定在首页顶部，滚动配方列表时不会跟着滑走
- 配方列表会联网从 Wikipedia/Wikimedia 搜索对应鸡尾酒缩略图，找不到图片或离线时自动显示原图标
- 配方列表和详情会按库存完整名称判断，把缺少的酒类、对应配料和鸡尾酒名称自动标红，更新“我的酒”后自动恢复或变红
- 浅色、深色、跟随系统显示模式
- App 主图标包含浅色、深色和 tinted 资源；浅色图标保留实底，深色和 tinted 使用透明背景适配 iOS 26 透明图标主题
- 底部功能栏展开时显示为一个更大的系统 Liquid Glass bar 并带中文名称，上滑收起后带柔和过渡动画变成三个独立圆形按钮
- 首页本月饮酒日历，可直接查看有记录的日期并进入当天记录
- 饮酒日历，可手填喝的酒名或从配方带入，支持每天多款酒、备注和多张照片
- 每日推荐小组件，支持小号、中号、大号、超大号和 accessory 尺寸
- 自定义 App 图标

## 运行到 iPhone

1. 用 Xcode 打开 `Cocktail60.xcodeproj`
2. 选择 `Cocktail60` scheme
3. 在 Signing & Capabilities 里选择你的 Apple 开发团队
4. 连接 iPhone，选择设备后点击 Run

最低系统版本：iOS 16。

如果只是先预览，可以在 Xcode 里选择任意 iPhone 模拟器运行。
