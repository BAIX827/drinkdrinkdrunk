# 微信小程序功能对照

基线为 `Cocktail60/BarWeb` 共用吧台。此前基础版缺少的模块已补入；下表列出实现与适配差异。

| 原功能 | 小程序入口与实现 | 状态 / 差异 |
| --- | --- | --- |
| 145 款配方、来源、搜索、收藏、筛选 | 发现 / 配方详情 | 复用原数据和规则 |
| 自建配方新增、修改、删除 | 发现 → 我的 / 配方编辑 | 用户文字原样保留 |
| 库存、分类与替代材料 | 我的酒 / 分类勾选 | 未勾选分类不算已有材料 |
| 瓶型、颜色和手绘 | 我的酒 → 编辑瓶子 | 9 瓶型、标准化坐标、撤销 / 清空 |
| 口味偏好、强度、实时成品 | 口味 DNA | 已实现 |
| 八维 DNA、推荐、评价、反馈 | 口味 DNA / 配方详情 | 原计算逻辑，原生界面用八维条形图呈现 |
| 个人口味和两杯比较 | 配方详情 | 已实现 |
| 步骤、计时、暂停与常亮 | 分步跟做 | 已实现，后台暂停 |
| 动作、瓶身绘画、液面、冰块与分层 | 跟做 Canvas | 12 类动作，原状态计算和美术的 Canvas 适配 |
| 杯型和自选颜色 | 跟做 / 自建配方 | 10 杯型、任意六位十六进制颜色 |
| 完成记账与外观保留 | 跟做 → 完成 / 日记 | 防重复保存，保存当时外观 |
| 背景音乐与音量 | 音乐控件 | 本地 MP3、主动开启、后台暂停 |
| 内置配方朗读 | 跟做 → 语音 | 中英文 822 条去重片段、6 分包，无语音插件依赖 |
| 任意自建文字朗读 | 跟做 → 语音 | WechatSI 适配已实现；需 AppID 授权启用，在线合成尚未实测 |
| 图片分享卡片 | 配方详情 → 分享卡片 | 8 模板，长配方自动延长 |
| 页面分享 | 配方详情 | 内置配方原生分享；本地自建配方用图片分享 |
| 月历、多条记录、备注、照片 | 日记 | 每篇最多 3 张，压缩 / 预览 / 编辑 / 删除 |
| 中英文界面 | 设置 → 语言 | 系统文案与原配方翻译，用户文字不自动翻译 |
| 三种主题、减少动态效果 | 设置 | 已实现 |
| 开场幕布、新手引导 | 首次打开 / 设置 | 10 步双语引导，可重看 |
| 本地数据、备份、迁移 | 设置与数据 | 交替文件保存、校验与失败保护 |

微信导航、表单、照片选择和分享菜单替代浏览器控件，界面不是逐像素复制。原生 iOS 专属桌面小组件、App 图标切换、Liquid Glass 和小红书内置网页读取器不属于共用吧台功能，小程序没有这些 iOS 专属入口。

验证范围与导入步骤见 [README.md](README.md)。当前交付为代码和已生成资源，未完成微信模拟器、真机验收或公众平台发布。
