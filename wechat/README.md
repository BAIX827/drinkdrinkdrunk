# 大喝特喝 · 微信小程序

原生 WXML / WXSS / JavaScript 工程，按现有共用吧台网页版的功能移植。配方、图片、音乐和内置配方中英文语音均已提供，直接导入即可，不需要启动网站、Node 服务或云开发，也不需要构建 npm。

此前说明中列为“暂未移植”的英文界面、音乐、瓶身手绘、杯型与换色、图片分享、跟做动作和引导现已补齐。逐项对照见 [FEATURE_PARITY.md](FEATURE_PARITY.md)。任意自建文字朗读的微信语音插件适配已实现，启用需自己的 AppID 和插件授权。

## 导入与预览

1. 打开微信开发者工具，选择「小程序 → 导入项目」。
2. 目录选择 **`C:\Users\64969\Desktop\drinkdrinkdrunk\wechat`**，不要选择仓库根目录或网页版 `dist`。
3. AppID 填自己有权限的小程序 AppID；`project.config.json` 当前已配置项目 AppID，其他开发者导入时需确认账号权限或换成自己的 AppID。工具允许测试号时可先调试，预览、分享和插件需实际账号权限。
4. 后端服务选 **「不使用云服务」**，导入后点击「编译」。第一次显示新手引导，之后进入 145 款配方首页。
5. 底部入口是「发现 / 我的酒 / 口味 DNA / 日记」。发现页的设置入口可以切换语言、主题，恢复备份和重看引导。
6. 用自己的 AppID 和有权限的微信账号点击「预览」，手机扫码检查。

使用支持 Canvas 2D 的稳定基础库，本项目以 3.x 为目标。手动导入无需开启“服务端口”，它只用于本地自动化，和云服务无关。语音按分包加载，首次播放相关片段需下载对应资源包，之后可使用已缓存资源。

## 自建文字的朗读配置（可选）

内置配方的中英文语音无需插件。任意自建文字无法预先打包，适配器支持 WechatSI 在线合成，默认关闭。

先在微信公众平台为自己的小程序添加并授权 WechatSI，再把 `project.config.json` 的 AppID 改成自己的 AppID。在仓库根目录执行下面命令，将 `版本号` 替换为后台实际获批的三段版本号：

```bat
node scripts/configure-weapp-speech.mjs 版本号
```

脚本写入 `app.json` 插件声明并启用 `shared/voice-provider.js`。插件提供方 ID 为 `wx069ba97219f66d99`，授权要求见 [微信官方示例](https://github.com/Tencent/Face2FaceTranslator)。不需要开通云开发。启用后，发送自建文字合成语音前会征求同意；文本将发送给微信语音服务。账号授权及在线合成尚未实测，需在你的 AppID 下验证。

## 数据与迁移

网页版「设置与数据」导出 JSON，发送至自己的微信文件传输助手。小程序「发现 → 设置 → 恢复 / 从网页版迁移 → 选择聊天中的文件」选择备份，也可粘贴较短 JSON。通过校验并确认替换后才覆盖当前数据。超过 500,000 字符的备份请用文件导入。

默认没有账号、云同步、数据库或后台上传。数据保存在 `wx.env.USER_DATA_PATH` 下的两个交替 JSON 文件，写入成功才切换指针；保存失败保留旧数据。读取异常停止写入并提供原始文件导出。卸载、清理数据和换机可能丢失记录，应定期备份。

照片本机压缩为 JPEG，每张最多 180,000 字符、最长边不超过 1280 像素；每篇最多 3 张。整体状态限制为 3,800,000 UTF-8 字节。超限备份拒绝导入并保留当前数据，需先减少照片。

## 开发与生成

普通导入无需运行命令。修改共享数据、逻辑或模板后，在仓库根目录执行：

```bat
cd /d C:\Users\64969\Desktop\drinkdrinkdrunk
npm.cmd run build:weapp
npm.cmd test
node scripts/verify-weapp.mjs "F:\微信web开发者工具"
```

构建复用原版数据、库存、口味、翻译、美术、步骤状态和分享逻辑，生成 `shared/engine.js`、`shared/data.js` 和双语 WXML。模板源在仓库根目录 `wechat-templates/`，修改后重新构建，不直接修改生成的 WXML。原 Web、iOS、Mac 源码保留。

列表 PNG 已提供。更新美术或新增配方可用可选开发依赖 `sharp` 执行 `node scripts/export-weapp-art.mjs`。运行中的瓶型、杯型和跟做场景使用 Canvas 矢量绘制。

修改内置语音文本时，依次执行 `node scripts/export-weapp-audio.mjs --prepare`、`scripts/record-weapp-voice.ps1`、`node scripts/export-weapp-audio.mjs`。这套开发流程需要 Windows System.Speech 的 Huihui / Zira 语音及构建工具 `lamejs`，现有成品资源无需重建。编码工具默认位于 `test-results/weapp-tools/node_modules/lamejs/lame.all.js`，可通过 `WEAPP_LAME_PATH` 指定替代位置。
